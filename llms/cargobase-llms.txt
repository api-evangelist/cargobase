# Cargobase

> Cargobase is a cloud-based Transportation Management System (TMS) for enterprise shippers, built to automate spot-buy and contract freight procurement across air, ocean, road, and courier modes. Shippers request quotes, compare carrier and forwarder rates apples-to-apples, book and execute shipments, track them in real time, audit invoices, and report on carbon emissions and provider performance from a single platform.

This llms.txt was generated by the API Evangelist enrichment pipeline from the catalog profile (apis.yml). Cargobase does not publish a public developer API or docs surface; the links below point to the product and company pages.

## Product
- [Spot buy procurement](https://www.cargobase.com/spot-buy-procurement): Automated spot-freight quoting and awarding.
- [Spot and contract rate management](https://www.cargobase.com/spot-and-contract-rate-management): Manage spot and contracted freight rates.
- [Shipment execution](https://www.cargobase.com/shipment-execution): Book and execute awarded shipments.
- [Transportation order management](https://www.cargobase.com/transportation-order-management): Manage transport orders end to end.
- [Visibility](https://www.cargobase.com/visibility): Real-time shipment tracking and status.
- [Cargo tracker](https://www.cargobase.com/cargo-tracker): Track cargo across modes and carriers.
- [Invoice audit](https://www.cargobase.com/invoice-audit): Freight invoice auditing and reconciliation.
- [Analytics](https://www.cargobase.com/analytics): Logistics and provider performance analytics.
- [Carbon visibility](https://www.cargobase.com/carbon-visibility): CO2 emissions reporting for shipments.
